# UC-Pathfinder-LaserHacks25

UC Pathfinder is a website that helps new students find the best UC to transfer into from IVC for their major, using transfer rates! The pathfinder also finds the average salary of graduates of that major from the university, and provides clubs that may help the user in pursuing their selected major at IVC.  By allowing them to find extracurriculars early in the school year, it greatly helps new students in becoming involved with IVC as well as to help with their upcoming applications to transfer.

Requires Python 3.10 and Flask
